# prueba-claude

## hola.py

Script sencillo que muestra la fecha y la hora actuales.

### Requisitos

- Python 3 (no necesita librerías externas)

### Cómo ejecutarlo

Desde la carpeta del repositorio:

```bash
python hola.py
```

Salida de ejemplo:

```
Hola! Fecha y hora actuales: 23/09/2026 17:55:12
```
